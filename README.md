# Memory Game (Игра «Найди пару»)

Интерактивная браузерная игра на развитие памяти, написанная на чистом JavaScript (Vanilla JS). Задача игрока - за минимальное количество ходов открыть все пары одинаковых карточек.

## Ссылка на проект (Демо)
🔗 [Поиграть в Memory Game](https://ikspass.github.io/memory-game/)

---

## Ключевые возможности проекта
* **Динамическая генерация поля:** Карточки каждый раз перемешиваются случайным образом.
* **Таблица лидеров:** Лучшие результаты сохраняются в `localStorage` и сортируются по количеству ходов и дате.
* **Плавные 3D-анимации:** Реализован красивый переворот карточек с использованием CSS 3D-transforms.
* **Адаптивный интерфейс:** Игра корректно отображается как на мониторах, так и на смартфонах.

---

## Используемые технологии
* **HTML5** - семантическая структура и модульные окна
* **CSS3** - Flexbox, Grid, 3D-анимации (`transform`, `perspective`), CSS-переменные
* **JavaScript (ES6+)** - модульная структура (`import/export`), делегирование событий, `localStorage` API, работа с DOM-деревом без `innerHTML`

## Установка и запуск на локальном компьютере

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ikspass/memory-game.git
   ```

2. **Перейдите в папку с проектом:**
   ```bash
   cd memory-game
   ```

3. **Запустите проект:**
   Поскольку в проекте используются ES6-модули (`type="module"`), обычное открытие файла `index.html` в браузере заблокируется политикой CORS. Проект нужно запускать через локальный сервер.
   
   * Если у вас установлен **VS Code**: установите расширение **Live Server**, нажмите правой кнопкой на `index.html` -> *Open with Live Server*.
   * Если у вас установлен **Node.js**:
     ```bash
     npx local-server
     ```
